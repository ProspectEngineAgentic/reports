B. The daily routine (do these every working day, in order)

  1. LISTEN — check the inbox first. Pull Saiful's LinkedIn inbox (inbox_triage.py). Read every new message and reply. For each: who is it, where did it come from, what do they want. Classify, ICP-score the sender, decide action, draft a reply in voice. Log it in the inbox tracker. Any reply from a live sequence = stop that sequence.
  2. RESPOND. Draft replies for genuine messages (prospect replies first, then warm inbound, then networking). Share with CEO; CEO/Saiful sends. Skip system spam, vendor pitches, and pure pleasantries (log + ignore).
  3. ENGAGE (nurture). Comment on 5–10 target prospects' posts, appreciate wins, follow new target company pages. Reply to comments on Saiful's own posts.
  4. VERIFY + SCORE. Take the next batch of sourced leads, verify live, score with the intent index, tier them, move to the queue.
  5. CONNECT. Send the day's personalized connection notes to Tier 1/2 (warm-up-first; ramp 10 -> 20/day). Each note hand-fit.
  6. FOLLOW UP. Send due M1–M4 to prior connects, after a fresh live-inbox check (never trust the tracker alone).
  7. SOURCE. Top up the candidate pool (one source slice) toward the 500 target.
  8. TRACK. Update the master tracker + inbox tracker. Note outcomes.

Weekly: re-score the nurture pool + uncontacted Tier 1/2, dedupe, review funnel metrics vs 02 §5, refresh content batch, short progress note to CEO.

C. The inbox / reply workflow (detail)

For every message in Saiful's inbox, capture and log:

Field What
who Name
from (origin) How it reached us: our sequence reply / comment-engagement / inbound cold / connection / client / personal
what they want Their ask in one line
intent class Prospect reply · Warm inbound · Networking · Vendor pitch (to us) · Recruiter/HR · Client · Personal · System · Decline
ICP fit Could they be a PE client? Y/N + persona (A/B/C/D) + intent tier (after profile check)
action Reply (draft) · Nurture · Decline politely · Ignore (log) · Route to client workstream
status Open / Drafted / Sent (by CEO) / Closed

Routing rules:
- Prospect reply (from our outreach): highest priority. Stop the sequence. Reply human, in voice, same working day. Aim for a call.
- Warm inbound / networking: reply light and curious, qualify gently. If ICP-fit founder/owner, flag as a prospect and add to the list.
- Vendor pitch to Saiful / recruiter / system: log and ignore (or one-line decline). Not prospects.
- Existing client (e.g. Robert=PDCA, Branko=Opcom): route to that client's workstream, do not mix.
- Personal: leave to Saiful. Log as personal, no draft.

ICP scoring of senders: use the same index as outbound (05). Fit gate first (B2B, 10–200 emp, target market, decision-maker). If fit, read their profile + recent posts for intent signal, score /100, tier. If we cannot see the profile yet (e.g. Sales Nav cooldown), mark verify profile and provisional-score from context.
